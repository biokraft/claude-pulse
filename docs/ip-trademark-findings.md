# IP / Trademark Findings — App Naming ("Claude Pulse" / "Clawd Pulse")

Date: 2026-07-27
Status: Researched. Decision: keep "Claude Pulse" for now; contact Anthropic
(marketing@anthropic.com) for permission before store submission.

## Anthropic side (primary risk)

- **CLAUDE is a registered US trademark**: USPTO Reg. #7645254 (serial
  97790228), filed 2023-02-10, registered 2025-01-07, class 42 (AI/NLP
  SaaS) — exactly this app's category. A second CLAUDE application
  (serial 98431492) is also on file. ANTHROPIC, MODEL CONTEXT PROTOCOL,
  and MCP filings exist too. No separate "Claude Code" or "Clawd"
  registration surfaced (medium confidence — search gaps possible).
  Sources: uspto.report/TM/97790228, trademarks.justia.com/977/90/.
- **Official policy**: Anthropic Trademark Guidelines
  (anthropic.com/legal/trademark-guidelines) — marks may be used only with
  explicit prior permission; requests via marketing@anthropic.com. No
  published safe-harbor naming formula (unlike OpenAI's explicit "no GPT
  in product names" rule). Commercial ToS grant no trademark license.
- **Enforcement precedent (decisive)**: Jan 2026, Anthropic legal forced
  "Clawdbot" to rename — "Clawd" deemed phonetically identical to
  "Claude"; even "Clawbot" was disallowed; project became "OpenClaw".
  So **"Clawd Pulse" is not a workaround** — sound-alikes are enforced.
  Sources: trendingtopics.eu, Wikipedia "OpenClaw".
- **Mascot**: the pixel-crab "Clawd" is Anthropic's own IP (used in
  official Claude Code onboarding/social). No public usage license. A
  lookalike sprite is a separate copyright/trade-dress exposure from the
  app name.
- Anthropic legal is active generally: ~8,100 DMCA takedowns of Claude
  Code source copies (Apr 2026).

## Garmin side (secondary)

- Connect IQ review is permissive; IP enforcement is reactive
  (complaint/DMCA-driven). Store hosts long-lived brand-named third-party
  apps (Tesla Link Widget, WatchGPT, paid "Tesla Remote – Wristla").
- But the SDK/Program Agreement puts all third-party-IP liability on the
  developer and lets Garmin remove any app for any reason. No evidence of
  stricter IP review for paid apps.

## Risk assessment

- Garmin review will almost certainly not block the name.
- Anthropic takedown/rename demand is plausible once the app is visible,
  and most costly *after* a paid launch (store reviews and listing history
  are lost on rename/delisting).
- Lower-risk pattern (if permission is not granted): neutral app name
  (e.g. "Quota Pulse"), descriptive nominative use only in the listing
  description ("usage companion for Claude Code"), original mascot design
  that is not a crab lookalike.

## Action items (before store submission — blocking)

1. Email marketing@anthropic.com requesting permission for the name
   "Claude Pulse" (and mascot usage, if keeping a Clawd-style sprite).
2. If no permission: rename listing to a neutral mark and redesign mascot
   before submitting to the store.
3. Repo/internal naming is irrelevant to this risk (private repo); only
   the public store listing, app name, icon, and screenshots matter.
