## [1.0.0] - 2026-08-17

First stable release. The relay leaves beta with prebuilt binaries, so installing it no
longer needs a Go toolchain or a source checkout.

### Added

- Prebuilt relay binaries for macOS and Linux on both Intel and ARM, published with a
  `checksums.txt` and build provenance attestation. `install.sh` downloads and verifies
  one instead of compiling, and falls back to building from source when no binary
  matches the platform.
- A Homebrew cask: `brew install biokraft/tap/claude-pulse-relay`.
- Quota readings are taken from the Claude Code statusline, which carries the same
  figures the relay used to poll Anthropic for. They arrive as they change rather than
  up to five minutes later, and cannot be rate limited, so the relay stops polling
  entirely while Claude Code is running.
- `claude-pulse-relay status` reports the relay, the tunnel, the usage poll, the cost
  hook and whether the watch has actually fetched anything, then lists what is wrong. It
  exits non-zero on any finding and never prints the access token.
- A tunnel supervisor that notices when `cloudflared` dies and restarts it, instead of
  leaving the watch pointed at an address that stopped answering.
- A pairing page at `/`, so scanning the QR code opens the URL and token with a copy
  button for each.
- A one-line installer that upgrades in place, preserves `~/.claude-pulse/`, smoke-tests
  the new binary before it replaces the old one, and rolls back if that fails.

### Fixed

- Daily cost was inflated by every relay restart. The per-session totals used to compute
  each increment lived in memory, so a restart re-counted a long-running session's whole
  cumulative cost. They are now held in the database and the increment is computed in
  the same transaction that records it.
- The cost page reported `0 tokens`. The relay read `context_window.input_tokens`, which
  does not exist at that level — Claude Code sends the session totals as
  `total_input_tokens` and `total_output_tokens`.
- The glance painted an opaque black box over the widget carousel, and its layout is
  rebuilt around what a round screen can actually show.
- The last usage reading and the poll backoff both survive a restart, so a relay
  restarted while rate limited serves its last known figures instead of zeros.
- Usage polls report why they failed. Every failure path used to return silently, which
  made expired credentials indistinguishable from a healthy relay.
- An installed service gets a usable `PATH`, so it can find `cloudflared` — launchd and
  systemd units inherit no shell environment.
- Sync ages are readable: `synced 8h 12m ago` rather than `synced 492m ago`.

### Security

- Tracked files are scanned in CI for personal data — home paths, hostnames, tunnel URLs
  and stray tokens — because this repository is public.
