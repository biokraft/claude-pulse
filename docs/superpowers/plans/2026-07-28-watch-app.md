# Claude Pulse Watch App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Connect IQ watch app (`watch/`): glance + 3 swipeable pages (quota rings, mascot/detail, cost) fed by the relay's `/api/v1/snapshot` endpoint via a 5-minute background temporal event.

**Architecture:** Background service fetches the snapshot and hands it to the app via `Background.exit`; foreground persists it to `Application.Storage`. All display logic reads Storage only. Pure logic (parsing, staleness, countdown formatting, pose engine, chart scaling) lives in `source/model/` as static functions with Run No Evil unit tests. Views draw directly in `onUpdate(dc)`.

**Tech Stack:** Monkey C, Connect IQ SDK 8.x, VS Code extension optional (CLI `monkeyc`/`monkeydo` sufficient), Run No Evil tests, `matco/connectiq-tester` for CI.

## Global Constraints

- App type: watch-app (`<iq:application type="watch-app">`) with glance scope. App id: generate once with `uuidgen`, keep stable.
- Devices (manifest products): `fenix8solar47mm`, `fr965`, `venu3` for dev; broaden before store submit.
- Snapshot contract (frozen, from relay): `five_hour_pct, seven_day_pct, five_hour_resets_at, seven_day_resets_at, is_active, active_count, today_cost_usd, today_tokens, daily[{day,cost_usd,tokens}], fetched_at, stale`. Timestamps RFC3339 UTC. Watch MUST tolerate `fetched_at == "0001-01-01T00:00:00Z"` + `stale:true` (relay pre-first-poll state).
- Design tokens: accent `0xCC7A56`; warning `0xC24B3A` at pct ≥ 85; screen bg `Graphics.COLOR_BLACK`; text primary `0xF7F5F0`-ish → use `Graphics.COLOR_WHITE`; muted → `Graphics.COLOR_LT_GRAY`. Ring: `dc.drawArc` from 90° clockwise, pct/100 of 360°, over full track arc.
- Staleness UI: data older than 15 min → show "synced Xm ago" caption and draw rings in muted color.
- Glance memory budget 32 kB: glance reads 4 pre-computed Storage values only, zero parsing/formatting beyond string concat.
- Storage keys (single dict under key `"snap"`): raw snapshot dict + `"fetchedEpoch"` (Number, Unix seconds computed at receive time).
- Settings (properties): `relayUrl` (string), `relayToken` (string), `accentColor` (number, default 0xCC7A56).
- Background: `Background.registerForTemporalEvent(new Time.Duration(300))`; re-register in `onSettingsChanged` and app start.
- Signing: `developer_key.der` at repo root sibling `watch/` — NEVER committed (gitignored already). Generate: `openssl genrsa -out developer_key.pem 4096 && openssl pkcs8 -topk8 -inform PEM -outform DER -in developer_key.pem -out developer_key.der -nocrypt`.
- Build check per task: `monkeyc -f watch/monkey.jungle -d fr965 -o /tmp/cp.prg -y developer_key.der` (adjust path); tests: compile with `--unit-test`, run `monkeydo /tmp/cp-test.prg fr965 -t`.
- Every conversational/manual step that needs the simulator: `connectiq &` first.
- Commit after each green task.

- [ ] **Step 3: Implement `Snap` module**

```monkeyc
// watch/source/model/Snapshot.mc
import Toybox.Lang;
import Toybox.Application;

module Snap {
    const STALE_SECS = 900;
    const WARN_PCT = 85;
    const WARN_COLOR = 0xC24B3A;

    function save(data as Dictionary, nowEpoch as Number) as Void {
        Application.Storage.setValue("snap", {"d" => data, "fetchedEpoch" => nowEpoch});
    }

    function load() as Dictionary? {
        return Application.Storage.getValue("snap") as Dictionary?;
    }

    function isStale(stored as Dictionary?, nowEpoch as Number) as Boolean {
        if (stored == null) { return true; }
        var d = stored["d"] as Dictionary;
        if (d["stale"] == true) { return true; }
        return nowEpoch - (stored["fetchedEpoch"] as Number) > STALE_SECS;
    }

    function ageMinutes(stored as Dictionary?, nowEpoch as Number) as Number {
        if (stored == null) { return -1; }
        return (nowEpoch - (stored["fetchedEpoch"] as Number)) / 60;
    }

    function countdown(resetsAtEpoch as Number, nowEpoch as Number) as String {
        var secs = resetsAtEpoch - nowEpoch;
        if (secs <= 0) { return "now"; }
        var days = secs / 86400;
        if (days >= 1) {
            return days.format("%d") + "d " + ((secs % 86400) / 3600).format("%d") + "h";
        }
        return (secs / 3600).format("%d") + "h " + ((secs % 3600) / 60).format("%d") + "m";
    }

    function parseIso8601(s as String) as Number {
        // expects YYYY-MM-DDTHH:MM:SSZ
        if (s.length() < 20) { return 0; }
        var y = s.substring(0, 4).toNumber();
        var mo = s.substring(5, 7).toNumber();
        var da = s.substring(8, 10).toNumber();
        var h = s.substring(11, 13).toNumber();
        var mi = s.substring(14, 16).toNumber();
        var se = s.substring(17, 19).toNumber();
        if (y == null || mo == null || da == null || h == null || mi == null || se == null) { return 0; }
        if (y < 1970) { return 0; }
        var opts = {:year => y, :month => mo, :day => da, :hour => h, :minute => mi, :second => se};
        var mom = Toybox.Time.Gregorian.moment(opts);
        return mom.value();
    }

    function pctColor(pct as Number, accent as Number) as Number {
        return pct >= WARN_PCT ? WARN_COLOR : accent;
    }
}
```

Note: `Gregorian.moment` interprets options in UTC when built from explicit fields on CIQ — VERIFY in simulator; if it applies local timezone, compute epoch manually (days-since-epoch arithmetic, leap-year aware) and keep tests as the oracle.

```monkeyc
// watch/source/model/Pose.mc
import Toybox.Lang;

module Pose {
    function compute(fiveHourPct as Number, sevenDayPct as Number, isActive as Boolean,
            hourOfDay as Number, inactiveSecs as Number,
            celebrateUntilEpoch as Number, nowEpoch as Number) as Symbol {
        if (nowEpoch < celebrateUntilEpoch) { return :celebrate; }
        if (fiveHourPct >= Snap.WARN_PCT || sevenDayPct >= Snap.WARN_PCT) { return :annoyed; }
        if (isActive) { return :working; }
        var night = hourOfDay >= 0 && hourOfDay < 6;
        if (night) {
            if (inactiveSecs >= 63) { return :sleeping; }
            if (inactiveSecs >= 60) { return :idleCollapse; }
            if (inactiveSecs >= 40) { return :idleDoze; }
            if (inactiveSecs >= 20) { return :idleYawn; }
        }
        return :idle;
    }
}
```

```monkeyc
// watch/source/background/FetchDelegate.mc
import Toybox.Background;
import Toybox.System;
import Toybox.Communications;
import Toybox.Application;
import Toybox.Lang;

(:background)
class FetchDelegate extends System.ServiceDelegate {
    function initialize() { ServiceDelegate.initialize(); }

    function onTemporalEvent() as Void {
        var url = Application.Properties.getValue("relayUrl") as String;
        var token = Application.Properties.getValue("relayToken") as String;
        if (url == null || url.length() == 0) {
            Background.exit(null);
            return;
        }
        Communications.makeWebRequest(
            url + "/api/v1/snapshot",
            {"token" => token},
            {:method => Communications.HTTP_REQUEST_METHOD_GET,
             :responseType => Communications.HTTP_RESPONSE_CONTENT_TYPE_JSON},
            method(:onResponse));
    }

    function onResponse(code as Number, data as Dictionary or String or Null) as Void {
        Background.exit(code == 200 ? data : null);
    }
}
```
